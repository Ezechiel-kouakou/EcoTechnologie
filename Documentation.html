Documentation de Ecotech

Bienvenue dans la documentation officielle de l'écosystème Ecotech. Cette infrastructure segmente 31 tables pour offrir des services de Shop, Fintech et Support CRM de manière isolée et performante.

Nos Services

EcoTech Shop

Gestion catalogue et stocks (Vues SQL optimisées).

EcoTech Bank

API de paiement interne/externe et transactions.

EcoTech CRM

Support client et gestion des messages commerciaux.

Authentification

L'API utilise des tokens JWT (Bearer Token) ou des API Keys pour les marchands.

  • Gérez vos accès dans le Panel Admin EcoTech.
  • Header requis : Authorization: Bearer <votre_token>

Endpoints API

Méthode Endpoint Table DB Description
GET /api/users users Liste des utilisateurs et rôles.
GET /api/bank/solde ecotechbank Consultation du solde bancaire.
POST /api/orders api_orders Initier un paiement externe (Merchants).
PUT /api/stock/{id} ecotechstock Mise à jour des stocks produits.

Intégration JavaScript

// Exemple d'initialisation de paiement EcoTech
const payLoad = {
    amount: 100.00,
    currency: 'EUR',
    order_token: 'unique_token_generated'
};

const response = await fetch('http://localhost/ecotech/api/orders', {
    method: 'POST',
    headers: {
        'Authorization': 'Bearer ' + API_KEY,
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(payLoad)
});

Architecture "Separation of Concerns"

L'utilisation de 31 tables permet de séparer les flux financiers (`ecotechbank`) des flux logistiques (`ecotechstock`). Cela garantit qu'une maintenance sur le catalogue n'interrompt jamais les transactions bancaires en cours.
